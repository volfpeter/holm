# Agent skills

Coding agent skills for working with the `holm` framework. Each subfolder is a self-contained skill that helps an agent follow `holm` conventions and patterns.

Available skills:

- [`holm-web`](holm-web): building or modifying web applications with `holm`.

## Installation

Agent skills live in your agent harness's `skills/` subfolder. To install a skill, copy its folder (the entire subdirectory, including `SKILL.md`, `references/`, etc.) into your agent config's `skills/` directory.
