Where things live

The short version — the design page and DESIGN.md have the full tour.

  • app/ The application package. Drop in a page.py, layout.py, or actions.py and it becomes a route, a layout, or an HTMX endpoint — the rotating greeting in the title is app/actions.py at work.
  • components/ The full BasecoatUI catalog, vendored as plain Python you own. It lives outside app/ so route discovery never touches it — see the showcase.
  • assets/ The sources you edit: app.css and app.js — the only two things that ever get built.
  • static/ Build outputs served at /static. Never edit by hand; the minified builds are committed so a fresh checkout runs and deploys as-is.

Develop

One command starts everything: the app with auto-reload, plus watchers rebuilding the dev stylesheet and JS bundle on every save. Edit, save, refresh. 

uv run poe start          # http://localhost:5000

uv run poe dev            # app only, dev assets
uv run poe preview        # app only, minified assets — what gets deployed

Checks run with ruff and mypy (strict); uv run poe check runs them all. Deploying serves the minified builds — run uv run poe build first, then any FastAPI host works; Vercel and FastAPI Cloud need no configuration. The details are on the design page.
