__holm_name__, Welcome

A fresh holm application: file-system based routing, server-rendered Python components, and no app build step. The sections below tour the scaffold — what's in it, what it's built on, and how to ship it.

What you get

Everything below is in the box, wired up and working — including this page.

  • File-system based routing

    Drop page.py, layout.py, or actions.py into a folder under app/ and it becomes a route, a layout, or an HTMX endpoint. No routes to register, no layouts to wire up.

  • Standard FastAPI

    Dependencies, validation, background tasks — the whole ecosystem. The same application can serve JSON APIs and server-rendered HTML.

  • Components in typed, async Python

    Rendering is htmy: JSX-like syntax, no template language. This page is a static template plus one Python action; the rotating greeting above is the dynamic part.

  • First-class HTMX

    Actions return HTML fragments that HTMX swaps in — dynamic updates without client JavaScript. The greeting in the title cycles through languages every 2 seconds.

  • No app build step

    Server-side rendering only — no bundler for your Python components. Stylesheets and scripts recompile on save in development and are built once, ahead of deployment.

  • Unopinionated styling

    This scaffold ships TailwindCSS and BasecoatUI, but any CSS framework works, and Jinja layouts are supported out of the box.

Backend

All server-side Python. holm walks app/ and registers everything below as standard FastAPI routes.

  • holm Application discovery: turns the modules in app/ into routes, layouts, and actions, and composes pages with their layouts automatically.
  • FastAPI The ASGI framework serving it all — dependencies, validation, and docs included.
  • fasthx Rendering glue between FastAPI and htmy: the same route can return JSON or rendered HTML depending on the request.
  • htmy Server-side rendering with pure, fully typed, async Python components — no template language to learn.
  • htmui Vendors the BasecoatUI catalog into components/ — the theme switcher in the header is one of them.

Frontend

What reaches the browser — and it's just HTML, CSS, and one small HTMX script.

  • BasecoatUI Accessible, themeable components in the shadcn spirit, called like any Python function from components/.
  • TailwindCSS Utility classes everywhere on this page; poe start recompiles the stylesheet while you edit.
  • HTMX Swaps in fragments the backend renders — the multilingual greeting is a single endpoint polling every 2 seconds.

Deployment

Deployments serve static/app.css and static/app.js, so build them first — then pick a target.

  1. 1

    Build the production stylesheet and JS bundle

    uv run poe build-prod-css
uv run poe build-prod-js
  2. 2

    Deploy to Vercel

    Import the repository — no configuration needed. [tool.fastapi] in pyproject.toml is the entrypoint.

  3. 3

    …or FastAPI Cloud

    uv run fastapi deploy
